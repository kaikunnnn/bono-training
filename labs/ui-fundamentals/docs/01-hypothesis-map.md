# 仮説マップ

企画が前提にしている仮説。オズの魔術師テスト(Phase 3)とデスクリサーチ(Phase 2)で検証する。
リスク = 外れた時の設計への影響大きさ / 不確実性 = 今の根拠の薄さ。

| # | 仮説 | リスク | 不確実性 | 検証手段 |
|---|------|--------|----------|----------|
| H1 | 初心者は「作る前」(構造を決める段階)で詰まる | 高(4ステップ構成の根幹) | 中 | 挫折談分類 + 観察セッション |
| H2 | 引用付きの根拠は初心者に「信頼」として届く(読み飛ばされない) | 高(差別化の核) | 高 | オズテストで引用への反応を観測 |
| H3 | 1セッション1時間で完走できる | 中 | 中 | オズテストで計測 |
| H4 | Figmaで実物を作る前提が初心者の障壁にならない | 中 | 中 | オズテスト参加者のFigma習熟を記録 |
| H5 | STEP4の「模範との比較」が答え合わせ/コピーに堕ちない | 高(BONO思想との一致点) | 高 | オズテストでSTEP4の発話を観測 |
| H6 | テイスト依存の低いお題(フォーム系)でも学びの満足感が出る | 中 | 中 | セッション後インタビュー |
