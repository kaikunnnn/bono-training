## 確定した標準形

### 1. 教え方: A表面+B折りたたみ
- 各ステップの表面は**問い駆動**: 説明2〜4文+引用チップ+「あなたのお題ではどうする?」の問い。答えるまで型は出ない
- 各ステップに**「パターン辞典」を折りたたみで常備**: 定義(DS引用+原典リンク)/ 基本の挙動 / 使用サービス の3行カード
- C(実例ギャラリー)は独立モードにしない。実例は引用チップ(実測観察)と比較画面(実物スクショ)が担う
- 根拠: 詳細は求められたときに出す(引用-04: Grammarly/Khanmigo/Duolingo Max)/ 説明2〜4文+即・問い(体験-01: Brilliant実測)/ パターン辞典はTakのビジョン(パターンを input→output する学習エンジン)

### 2. ステップ数: 習熟連動(スイッチではなくカリキュラム構造)
- **新しいパターンを学ぶお題 = 7ステップ**(足場あり: 読み取り2+構造2+パターン2+言葉1)
- **同じパターンの再出題 = 4ステップ**(足場外し: 読み取り1+構造1+パターン1+言葉1)
- 根拠: ガイド付き→自力の二段構え(体験-06: freeCodeCamp Workshop→Lab / Frontend Mentor)
- 実装: STEPS7=お題01で使用中 / STEPS4=お題02(再出題型)用に温存済み

### 3. 変わらない骨格(体験設計書 01-experience-design.md のA-1〜A-8)
ブリーフ4点キット / 合格条件先出し / 3段ヒント任意 / 3点比較+観点別+再比較ループ / 言語化必須+蓄積

## お題→ステップ変換の原型(次フェーズで手順書化)

1. お題が運ぶ**新パターン**を特定(例: お題01=テキスト入力・ソーシャルボタン・CTA)
2. 新パターンなら7ステップ、再出題なら4ステップの骨組みを選ぶ
3. 各ステップに (a)説明2〜4文 (b)台帳からの引用チップ (c)問い(選択 or 記述+理由) (d)型(回答後リビール) (e)パターン辞典カード を、**台帳にある根拠だけで**埋める
4. ブリーフの完成条件チェックリストを決定論チェック(付録A)から生成し、比較画面でも同じ物差しを使う
