# プロトタイプ組み立て計画(最終工程表)

- 2026-07-06 確定。以後この計画で最後まで実行する

## ゴール定義(完成判定の物差し)

**目的(Takの言葉から)**: AIだけでデザインシステムを参照し、ステップ設計・お題設計を行い、Webページにしたときに「どういう内容と進め方になるか」をTak自身が見て判断できるプロトタイプ。

**ユーザー価値(学習者にとって)**: 実務的なお題を、実在デザインシステムの引用付きステップで進めながら、基礎UIパターンを「作りながら」学べる。DailyUIに無い②知識インプットと④フィードバック(比較)がある。

### 完成チェック項目(P5でこの5つを判定する)

| # | チェック | 合格基準 |
|---|---|---|
| G1 | 通し体験 | お題01をブリーフ→学習→制作→比較→完了まで1本で体験できる |
| G2 | 嘘のなさの可視化 | パターン教育の主張に実在DS引用チップが付き、原文+URLに到達できる。台帳にない主張ゼロ |
| G3 | 学習ループ完備 | ①キット ②マイクロステップ ③制作支援 ④観点別比較 ⑤言語化、の5局面が全部ある |
| G4 | 体験設計の反映 | A-1〜A-8の設計判断が画面上で確認できる |
| G5 | 進め方の判断材料 | Takが「この内容と進め方でいけるか」を判断できる情報密度(内容の薄いガワだけになっていない) |
