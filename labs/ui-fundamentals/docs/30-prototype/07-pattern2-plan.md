# パターン2計画 — 初心者に分かりやすく、魅力的な体験へ

- 2026-07-07。前提: **v0.4(パターン1)は保存し、別ファイルとしてパターン2を作る**。中身の方法論(4層引用・制作センター・情報は与える等)は同じ。変えるのは体験設計・UI・伝え方・導入。

---

## 1. 現状監査 — 初心者の目でv0.4を見ると何につまずくか

### A. 体験設計の穴
| 箇所 | 問題 |
|---|---|
| 開始直後 | **オリエンテーションが無い**。初見の人は「これは何をするサービスで、私に何が起きるのか」を知る前にお題カードに放り込まれる |
| 感情の設計 | 出迎え・励まし・達成の演出がゼロ。初心者の最大の敵は「自分にできるか」という不安なのに、**不安の先回り**(うまく作れなくて当たり前、途中でもOK)が弱い |
| インプット→制作の橋 | 「Figmaで作りはじめる」ボタンだけ。**Figmaの最初の一歩**(フレーム390×844を作る、から)が無いので、初心者はFigmaを開いた瞬間に固まる |
| 比較への橋 | スクショの撮り方(Figmaのエクスポート手順)の案内が無い |
| 完了 | 祝福が `alert()`(ブラウザの素の警告ダイアログ)。60分の努力の結末として最悪の体験 |

### B. UIデザインの穴
| 箇所 | 問題 |
|---|---|
| 温度 | 白黒のワイヤー+α。機能はあるが**魅力がない**。「デザインを学びに来た人」が最初に見る画面としては説得力を欠く(教材自身がデザインの手本であるべき) |
| 密度 | 1画面の文字量が多く、行長も長い。読み物として息継ぎがない |
| 視覚言語 | カードの種類(基本/やること/まとめ)の区別が小さなバッジだけ。スキャンで構造が掴めない |
| ガイドの不在 | 「誰が教えてくれているのか」の人格が画面に存在しない。文章が「システムの説明文」に見える |

### C. 言葉遣いの穴(具体例)
| 現状の言葉 | 問題 → 言い換え候補 |
|---|---|
| 完成条件 / 品質の物差し | 硬い →「できたかチェック」 |
| 言語化(必須) | 教育用語 →「今日の学びを、ひとことに」 |
| 実測観察 | 研究用語 →「実際に調べた記録」 |
| 視覚階層 | 専門用語(初出で未定義)→「見る順番」+初出で1行説明 |
| 脱出路 / 破壊的操作 | 内輪の比喩・訳語 →「ログインへの案内」「取り返しのつかない操作」 |
| 長い複文(60字超) | 息切れ → 1文40字目安・1段落3文まで |

### D. ステップ導入の穴
| 箇所 | 問題 |
|---|---|
| 各画面の冒頭 | 「このページで何をするか・何分かかるか・なぜやるか」の導入の一言が無い(ブリーフとインプットには一部あるが、声として一貫していない) |
| カード間 | 基本1→2→やること…が**並列に置かれているだけ**で、「前のカードとどうつながるか」の接続詞が無い |
| 初回とリピート | 初見の人と2周目の人が同じ画面(はじめての人向けの説明を畳む仕組みが無い) |

## 2. パターン2の設計原則(この考え方でデザインする)

**中心思想: 「教材そのものが、良いUIデザインとおもてなしの見本であること」。** 初心者は内容の前に、体験の温度で続けるかを決める。

1. **ガイドに人格を与える** — 画面の説明文を「ガイドの声」(小さなアバター+吹き出し)に変える。各画面の冒頭で ①ここで何をするか ②何分か ③不安の先回り、を1〜2文で話す。これがステップ導入の器になる
2. **言葉のスタイルガイドを先に決める** — 上の言い換え表+原則(1文40字目安 / 専門用語は初出で日本語の言い換え / 「あなた」に話しかける / 命令形でなく誘い形)。全文言をこれで書き直す
3. **不安の先回り** — 開始時30秒オリエンテーション(読む→作る→見比べる、の3コマ)/ 「うまく作れなくて大丈夫、見比べるところまでがワンセット」を最初に言う / Figmaの最初の一歩カード / スクショの撮り方
4. **視覚の温度と構造** — アクセント1色+柔らかい面の色で「基本(青系)/やること(緑系)/まとめ」をカードの色面で区別。見出しを大きく、行長を絞り、段落を短く。達成はコンフェッティ的な祝福画面で(alert廃止)
5. **リズム** — 1カード=1呼吸。カード間に「つぎは、実物を見に行きます →」のような接続の一言。flowbarは大きく・現在地が一目で
6. **変えないもの** — 4層引用(参考リンクカードの格は維持)/ 情報は与える・構造は与えない / フィールドワーク / 3点比較 / 学びのひとこと。**方法論はパターン1と同一**
