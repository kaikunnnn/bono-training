# 参考デザイン「margin」の分析（SaaSのテイスト変更用）

- 元画像: 1600×1200 のスクリーンショット（アプリの枠は横 1518px）。数値は画像のピクセルを実寸として読んだ目安
- 色は画像から Pillow で抜き出した値（文字は縁のなじみで少しずれる）

## 全体

- 外の背景 #E6E7EC の上に、角丸 約40px のアプリ枠（#F2F2F2）が乗る
- 色はほぼ白〜グレーの単色。色が付くのは「青1色（#1552E0 前後）」「マイナスを表すピンク（#E9337E 前後）」「プラスの緑（#16A543）」「通知のオレンジ（#F37509）」だけ
- 例外は右上のヒーローカード1枚（濃紺→オレンジのグラデーション）。強調はここ1か所に集める
- 線をほとんど使わず、面の明るさの差（#F2F2F2 → #FAFAFA → #FFFFFF）で重なりを作る
- 文字は欧文のネオグロテスク（Inter / Geist 系）。見出しは太くせず、大きさで差をつける

  - グループ見出し「Analyze」: 12〜13px のグレー（#868686）
  - 下部: 通知（オレンジの丸バッジ 20px）・設定・ヘルプ。区切り線の下にユーザー（丸い写真 40px＋名前＋役割）

## タスク管理のダメUIに当てはめるときの考え

- 構成（サイドバー・一覧・右の詳細・削除モーダル）と、入れてある配色のミス14項目はそのまま残す。変えるのは見た目のテイストだけ
- 参考デザインは配色がとても上手なので、そのまま写すとミスが消える。ミスは「このテイストの中で起きそうな形」に置き換える
  - 例: 選択中のナビを黒ではなく主色の青で塗る（項目2）／チップの文字を淡い色のまま（項目11）／サブ文字をさらに薄く（項目8）
- 斜線や大きな数字など、このデザインらしさは残す

## サイズの調整（2026-10-25）

- 参考画像の数値をそのまま実寸にすると大きすぎた（オーナー指摘）。参考画像は拡大した見せ方の画像で、実際の画面より大きいと考える
- ほかのSaaSタブと同じ 1280×800 に合わせ、普通の業務アプリの大きさに直した。比率は参考のまま残す
