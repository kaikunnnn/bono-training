🧭 UI Trainer — プロトタイプ・パターン一覧

改善ループの各世代をすべて残しています。番号が大きいほど新しく、直近ループの成果は5A / 5B / 5C(入口の動機設計・3変種)です。

第3ループ — 「やりたい!」の入口設計(3変種・中身は共通)
5A ビフォー → アフター最新有力 「よくある初心者の画面」vs「実物(Airbnb)」を入口で並置。“センスの差ではなく、決めごとの差”で不安を反転させる案。 5B 60分後のあなた最新 完成形をぼかして予告+身につくスキル+「ポートフォリオの1ページになる」。成果の見える化で誘う案。 5C 間違い探し最新有力 「プロが直したい所が7つ。いくつ見えますか?」で引き込み、完了画面で再挑戦→“見える目”の成長を実感させる案。5Aとの統合が本命候補。
