# 2026年9月のサイト移行後: /guide の重複とインデックス登録

## 対応方針

- 同じ本文を持つ `/guide/{slug}` と `/contents/{slug}` は `/guide` を検索上の正規 URL にする。
- `/contents` はレッスンの動画、進捗、前後移動に使うため残す。本文を照合できた6組のみ canonical を変更する。
- サイトマップには正規 URL の `/guide` のみ掲載し、該当する `/contents` は除外する。
- 重複する `/contents` の Article 構造化データは出さず、正規の `/guide` 側だけで出す。
- 有料の `/contents` はサイトマップから外し、ページには `noindex,follow` を付ける。無料の非重複記事は自己 canonical のまま残す。
- 既存の5件の `/contents` → `/guide` 恒久リダイレクトは維持する。本文が異なる同名ページは対象にしない。

対象6件: `portfolio-01`、`rdm-howtostart-roadmap`、`beginner-to-uiux-designer-examples`、`become-uiux-designer-beginner-guide`、`how-to-find-jobs-for-beginner-designers`、`uiux-interview-tips-and-checkpoints`。

## 9/24の追加調査と修正

- 公開中の `/guide` 15件はすべてHTTP 200で、自己 canonical があり、`/guide` 一覧からリンクされていた。`robots.txt` によるブロックもない。サイト側で確認できる範囲では、4件が「検出 - インデックス未登録」となる直接の障害は見つからなかった。
- 15件中4件はCMSの説明文が空で、検索向けの `<meta name="description">` がなかった。本文に沿う説明文を4件に設定し、CMS側で説明文が入ればそちらを優先する。
- サイトマップは従来、掲載URLすべてに生成時刻を `<lastmod>` として付けていた。実際の更新日が取得できる `/guide` にCMSの `_updatedAt` を使い、取得できないURLは更新日を省略する。有料ガイドは有料記事と同様にサイトマップから除き、`noindex,follow` とする。
- クリック減少が目立った `/contents/designer-uiux-mac-2025` はHTTP 200、自己 canonical、タイトルと説明文も確認できた。9/8–14の9クリックから9/15–21の1クリックへの変化は、ページのHTTP/metadataだけでは説明できない。GSCでの比較結果は次節に記録する。
- 追加監査で、Webflow経由の旧 `/contents` 221件すべてがHTTP 200・自己canonicalで公開されている一方、現行サイトマップには含まれていないことを確認した。非会員向けに実質的な本文が表示される29件を選び、現行サイトマップに追加した。動画レッスンなど会員向け主体のページは含めない。Sanity側に同じスラッグが移植された場合は重複させず、有料化された場合も掲載しない。公開サイトマップは332→361件（`/contents` 240→269件）。GSCへ9/24に再送信し、「成功・検出361ページ」を確認した。これはサイトマップの読み込み結果であり、361ページのインデックス登録やクリック数の回復を意味しない。

### 旧URL・新URLの合算確認（9/24）

同じGSCプロパティの「検索パフォーマンス → ページ」で、移行前9/8–14と移行後9/15–21を比較し、表示された旧URLと新URLの行を合算した。**いずれも9/24のcanonical・サイトマップ修正より前の検索実績**であり、修正の効果測定ではない。

| 対応URL | クリック（前→後） | 表示回数（前→後） | 判定 |
| --- | ---: | ---: | --- |
| `/contents/portfolio-01` + `/guide/portfolio-01` | 7→1 | 98→63 | 新URLの行はこの期間のページ別表に出ず、旧URLの減少を補っていない。 |

本文重複のため9/24に正規化した6組の `/contents/{slug}` + `/guide/{slug}` は、ページ別表に表示された範囲で合計クリック16→7、表示492→273。最大の表示減少は `become-uiux-designer-beginner-guide` の旧新合算201→50。旧URLから新URLへ評価が移るだけで移行直後の減少を説明することはできない。まずGoogleの再クロールと正規URL選択を確認し、その後の7日間実績を同条件で比較する。

ページ別表の行を足した値は、プロパティ全体のカードの合計と一致しない。GSCは両者で集計単位が異なり、表の行やフィルタにも制限がある。したがって上記の合算値を全体のクリック減少27件へそのまま配分しない。新URLの行がない場合は「ページ別表に実績なし」と読み、未登録やクリック0を単独では断定しない。

インデックス登録レポートの最終更新日は9/21。**すべての既知のページ**の未登録3,362件（うち重複698件、クロール済み未登録2,477件）は送信済み以外のURLも含む別の母集団。**すべての送信済みページ**は192件中、登録162件・未登録30件。未登録30件は、未クロール24件、重複2件、クロール済み未登録2件、404が1件、Googleが別の正規URLを選択したものが1件。698件を現在のサイトマップの重複数として扱わない。
